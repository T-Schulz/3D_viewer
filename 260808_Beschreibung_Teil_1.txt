 Dortmund in JavaScript oder Python zu bauen und das Ergebnis kostenlos
  auf einer GitHub-Pages-Seite zu hosten.Das originale DXF-Format der 
  Stadt Dortmund ist für das Web jedoch ungeeignet (zu große Dateien, 
  kein nativer Browser-Support). Für eine flüssige Web-Darstellung 
  müssen Sie die Daten vorab konvertieren.
  Strategie für das Web: Welches Format für welchen Zweck?
  DXF (Rohdaten): Ungeeignet für das direkte Laden im Browser. 
  Muss konvertiert werden.
  JSON / GeoJSON / CityJSON: Ideal für Metadaten und vereinfachte 
  3D-Strukturen. Große Datensätze müssen komprimiert werden.
  CSV: Gut für Tabellen (z.B. ID, X, Y, Z, Gebäudehöhe), aber 
  ineffizient zur direkten 3D-Visualisierung im Browser.
  glTF / GLB: Der Web-Standard für 3D-Grafiken. 
  Konvertieren Sie die Daten vorzugsweise in dieses Format, um 
  maximale Performance zu erzielen.
  Option 1: Der reine JavaScript-Viewer (Ideal für GitHub Pages)
  GitHub Pages kann nur statische Dateien (HTML, CSS, JS) ausführen. 
  Ein JavaScript-Viewer ist die eleganteste Lösung, da die gesamte 
  Berechnung direkt beim Nutzer im Browser stattfindet.
  Vorbereitung (Datenkonvertierung)
  Da JavaScript DXF-Dateien nur schwer verarbeiten kann, nutzen Sie 
  am besten kostenlose Desktop-Tools wie Blender oder QGIS mit dem 
  Plugin Qgis2threejs, um die DXF-Kacheln einzulesen und als glTF 
  (.gltf / .glb) oder Three.js JSON zu exportieren.

Option 2: Der Python-Weg (Für lokale Tests oder Server)
Wenn Sie JSON- oder CSV-Koordinatenpunkte direkt parsen und daraus 
Geometrien erzeugen möchten, eignet sich Python hervorragend.
Hinweis: Python-Code läuft nicht nativ auf GitHub Pages. 
Sie können Python aber nutzen, um eine interaktive HTML-Datei zu 
generieren, die Sie dann auf GitHub hochladen.Lösung mit pydeck 
(Generiert HTML aus Daten)Falls Sie Ihre Daten als CSV (mit Spalten 
für Längengrad, Breitengrad und Höhe) vorliegen haben, können Sie mit 
Python im Handumdrehen einen Viewer bauen, der eine fertige HTML-Seite 
ausgibt:

python

import pydeck as pdk
import pandas as pd

# Angenommen, Sie haben die DXF-Daten in eine CSV-Tabelle extrahiert
# mit den Spalten: 'lng', 'lat', 'height' (Gebäudehöhe)
data = pd.read_csv("dortmund_gebaeude.csv")

# 3D-Gebäude-Ebene definieren
layer = pdk.Layer(
    "PolygonLayer",  # Oder ColumnLayer/MeshLayer je nach Datenstruktur
    data,
    get_polygon="-", # Geometriedaten der Grundrisse
    get_elevation="height",
    get_fill_color="[200, 30, 0, 160]",
    elevation_scale=1,
    extruded=True,
)

# Kartenansicht auf Dortmund zentrieren
view_state = pdk.ViewState(latitude=51.5136, longitude=7.4653, zoom=14, pitch=45)

# Render und Export als HTML-Datei
r = pdk.Deck(layers=[layer], initial_view_state=view_state)
r.to_html("index.html")

        // 1. Three.js Grund-Setup
        const scene = new THREE.Scene();
        scene.background = new THREE.Color(0x1a1a1a); // Dunkler Hintergrund für besseren Kontrast

        const camera = new THREE.PerspectiveCamera(60, window.innerWidth / window.innerHeight, 0.1, 1000);
        camera.position.set(100, 100, 100);

        const renderer = new THREE.WebGLRenderer({ antialias: true });
        renderer.setSize(window.innerWidth, window.innerHeight);
        document.body.appendChild(renderer.domElement);

        const controls = new THREE.OrbitControls(camera, renderer.domElement);
        
        // Lichtquellen hinzufügen
        const light = new THREE.DirectionalLight(0xffffff, 1.2);
        light.position.set(200, 400, 300);
        scene.add(light);
        scene.add(new THREE.AmbientLight(0x666666));

        // Hilfsnetz am Boden zeichnen
        const gridHelper = new THREE.GridHelper(500, 50, 0x444444, 0x222222);
        scene.add(gridHelper);

        // 2. CSV laden und parsen
        fetch('daten.csv')
            .then(response => response.text())
            .then(csvText => {
                parseAndRenderCSV(csvText);
            })
            .catch(err => {
                document.getElementById('status').innerText = "Fehler beim Laden der CSV!";
                console.error(err);
            });

        function parseAndRenderCSV(text) {
            const lines = text.split('\n');
            let baseLinesCount = 0;

            // Erste Zeile sind die Header (id, x, y, height)
            const headers = lines[0].split(',');

            // Offsets, um das Modell im Ursprung (0,0,0) zu zentrieren
            let offsetX = 0;
            let offsetY = 0;
            let firstPoint = true;

            // Standard-Material für die Gebäude
            const material = new THREE.MeshLambertMaterial({ color: 0x00a8ff });

            for (let i = 1; i < lines.length; i++) {
                const line = lines[i].trim();
                if (!line) continue; // Leere Zeilen überspringen

                const values = line.split(',');
                const x = parseFloat(values[1]);
                const y = parseFloat(values[2]);
                const height = parseFloat(values[3]);

                if (isNaN(x) || isNaN(y) || isNaN(height)) continue;

                // Beim ersten Gebäude setzen wir den Nullpunkt fest
                if (firstPoint) {
                    offsetX = x;
                    offsetY = y;
                    firstPoint = false;
                }

                // Lokale Koordinaten berechnen (Zentrierung)
                const localX = x - offsetX;
                const localZ = y - offsetY; // In Three.js ist Z die Tiefe (horizontal) und Y die Höhe (vertikal)

                // 3D-Klotz (Box) für das Gebäude erstellen
                // Breite: 10m, Tiefe: 10m (als Platzhalter für die Grundfläche), Höhe aus CSV
                const geometry = new THREE.BoxGeometry(10, height, 10);
                
                // Den Drehpunkt der Box an die Unterseite verschieben, damit sie auf dem Boden steht
                geometry.translate(0, height / 2, 0);

                const mesh = new THREE.Mesh(geometry, material);
                mesh.position.set(localX, 0, localZ);
                
                scene.add(mesh);
                baseLinesCount++;
            }

            document.getElementById('status').innerText = `${baseLinesCount} Gebäude aus CSV gerendert.`;
            animate();
        }

        // 3. Render-Schleife
        function animate() {
            requestAnimationFrame(animate);
            controls.update();
            renderer.render(scene, camera);
        }

        // Fenstergröße anpassen
        window.addEventListener('resize', () => {
            camera.aspect = window.innerWidth / window.innerHeight;
            camera.updateProjectionMatrix();
            renderer.setSize(window.innerWidth, window.innerHeight);
        });
