Das Prinzip von CityJSON verstehen
Ein typisches CityJSON-Modell besteht im Kern aus zwei Listen:
vertices: Eine lange Liste aller 3D-Koordinatenpunkte [X, Y, Z] im Raum.
CityObjects: Die eigentlichen Gebäude. Diese enthalten keine eigenen Koordinaten, sondern Verweise 
(Indizes) auf die vertices-Liste, um die Wände und Dächer zu formen.

Was machen Sie mit den GML-Dateien?
Da das direkte Laden von .gml im Browser zu extremen Rucklern führt, sollten Sie Ihre GML-Dateien vor 
dem Hochladen auf GitHub in CityJSON konvertieren.
Das offizielle, kostenlose Befehlszeilen-Tool der CityJSON-Entwickler heißt citygml-tools. Sie können 
es auf Ihrem Computer installieren und Ihre Dortmund-GML mit einem einzigen Befehl umwandeln:

bash
citygml-tools to-cityjson dortmund_kachel.gml

Verwende Code mit Vorsicht.
Das Tool generiert daraus automatisch die performante dortmund_kachel.city.json, die Sie direkt für 
das obige Skript verwenden können.
