3D Stadtmodell Dortmund

Experimentelle Web-Viewer zur Visualisierung offener Geodaten in verschiedenen Formaten.

Web Standard

1. glTF / GLB Viewer

Visualisierung über eine in glTF konvertierte 3D-Kachel. Bietet die beste Performance, flüssige Schatten und echte 3D-Meshes via Three.js.

Viewer öffnen
Strukturiert

2. JSON / CityJSON

Lädt semantische Gebäudedaten aus einer JSON-Struktur. Ideal, wenn zusätzlich zur Geometrie auch Attribute wie Baujahr oder Nutzung dargestellt werden sollen.

Viewer öffnen
Koordinaten

3. CSV Punkt-Parser

Liest rohe X/Y-Koordinaten und Höhenangaben direkt aus einer CSV-Tabelle ein und generiert die 3D-Körper dynamisch zur Laufzeit im Browser.

Viewer öffnen
Prerendered

4. Pydeck Map-Viewer

Eine via Python (Pydeck) generierte, interaktive Karten-Oberfläche, eingebettet auf einer Mapbox-Karte mit extrudierten Gebäude-Polygonen.
